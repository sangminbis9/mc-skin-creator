# 공개 정책·지원 페이지 게시 초안

실제 운영자와 문의처가 제공되지 않아 아직 공개하지 않은 초안입니다. 아래 항목을 확정하고 본인이 운영하는 HTTPS 사이트에 게시한 후 `store.config.json`에 URL을 넣으세요. 현재 웹 데모의 예전 개인정보 페이지를 그대로 제출하지 마세요.

## 운영자가 채울 정보

- 운영자/개인정보처리자 이름 및 연락 이메일
- 적용 국가·지역에 필요한 추가 개인정보 안내와 시행일
- 실제 Cloudflare 계정의 로그·사용량·오류 진단 보관 기간
- 개인정보 관련 요청 방법과 처리 절차

## 개인정보 페이지에 포함할 본문

‘마크 스킨 뚝딱’은 사용자가 직접 선택하고 동의한 사진을 기기에서 축소·압축한 후 Cloudflare 스킨 생성 서버 및 Cloudflare Workers AI로 전송하여 외형 특징을 분석하고 스킨을 만듭니다. 선택한 사진은 최대 5장이며, 사진을 보내지 않아도 샘플 편집과 보관함 기능을 이용할 수 있습니다.

앱 서버는 업로드 사진과 생성 스킨을 의도적으로 영구 저장하지 않습니다. 요청 중 메모리 처리와 별개로 서비스 사용량 집계와 오류 진단이 보관될 수 있으며, 인프라 운영자는 네트워크 및 운영 메타데이터를 처리할 수 있습니다. [Cloudflare 개인정보 정책](https://www.cloudflare.com/privacypolicy/)과 [Workers AI 데이터 사용 안내](https://developers.cloudflare.com/workers-ai/platform/data-usage/)도 함께 안내합니다. 실제 보관 기간과 처리자를 확인한 후 정책을 확정하세요.

기기에는 중복 생성 방지를 위한 결과 스킨·특징 정보·입력 해시를 최대 24시간 재사용하는 캐시가 저장될 수 있습니다. 만료 항목은 다음 생성 요청에서 제거되며, 사용자는 앱의 개인정보 화면에서 캐시를 지울 수 있습니다. 원본 사진은 이 캐시에 저장하지 않습니다.

사용자가 보관함에 직접 저장한 스킨은 개별 삭제할 때까지 기기에 남습니다. 앱 삭제나 기기 초기화 시 사라질 수 있습니다. 외부 파일로 내보낸 스킨은 사용자가 선택한 저장 위치의 정책을 따릅니다. iOS 공유 메뉴의 대상 앱과 저장 위치는 사용자가 선택합니다.

광고 또는 추적 SDK가 없고 계정 생성도 요구하지 않습니다. 스튜디오 링크 공유는 공개 서비스 주소를 전달하며 개인 사진이나 스킨을 자동으로 게시하지 않습니다.

## 지원 페이지에 포함할 본문

앱 이름: 마크 스킨 뚝딱 - 사진 한장으로 나만의 스킨 만들기

- 생성이 마감되었다면 다음 이용 가능 시각을 확인하세요. 샘플 편집과 보관함은 계속 사용할 수 있습니다.
- HEIC 파일을 읽지 못하면 JPEG 또는 PNG로 변환해 다시 선택하세요.
- 내보내기 메뉴에서 ‘파일에 저장’을 선택하면 PNG 원본을 보관할 수 있습니다.
- 중요한 스킨은 앱을 삭제하기 전에 외부 파일로 내보내세요.
- 스킨 생성 결과와 보이지 않는 부분은 실제와 다를 수 있습니다.

문의처에 **실제 지원 이메일**을 명시하고 앱 버전, iOS 버전, 재현 단계 등 최소한의 정보를 요청하세요. 얼굴 사진·Apple 비밀번호·API 키는 지원 요청에 첨부하도록 요구하지 마세요.
